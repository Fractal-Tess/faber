<Section
  title="Quick Example <span class='light-text'>JavaScript SDK</span>"
  description="See how easy it is to execute tasks with Faber using our JavaScript SDK."
>

```typescript
import { FaberClient, TaskBuilder } from '@faber/runtime-sdk';

const client = new FaberClient({
  baseUrl: 'http://localhost:3000',
  apiKey: 'your-api-key',
});

// Build and execute a task sequence
const builder = new TaskBuilder()
  .single({ cmd: '/bin/echo', args: ['Hello, Faber!'] })
  .parallel([
    { cmd: '/bin/sleep', args: ['1'] },
    { cmd: '/bin/sleep', args: ['1'] },
  ]);

const results = await client.executeGroup(builder);
console.log(results);
```

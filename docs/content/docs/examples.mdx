## Simple Command

Execute a single command and capture its output:

```bash
curl -X POST http://localhost:3000/api/v1/execute \
  -H "Content-Type: application/json" \
  -d '[
    {
      "cmd": "/usr/bin/echo",
      "args": ["Hello, Faber!"]
    }
  ]'
```

**Response:**
```json
[
  {
    "stdout": "Hello, Faber!\n",
    "stderr": "",
    "exit_code": 0,
    "stats": {
      "memory_peak_bytes": 0,
      "cpu_usage_percent": 0,
      "pids_peak": 0,
      "execution_time_ms": 5
    }
  }
]
```

## Sequential Tasks

Execute multiple tasks in sequence, where each task runs after the previous one completes:

```bash
curl -X POST http://localhost:3000/api/v1/execute \
  -H "Content-Type: application/json" \
  -d '[
    {
      "cmd": "/usr/bin/gcc",
      "args": ["hello.c", "-o", "hello"],
      "files": {
        "hello.c": "#include <stdio.h>\n\nint main() {\n    printf(\"Hello, World!\\n\");\n    return 0;\n}\n"
      }
    },
    {
      "cmd": "./hello"
    }
  ]'
```

**Response:**
```json
[
  {
    "stdout": "",
    "stderr": "",
    "exit_code": 0,
    "stats": {
      "memory_peak_bytes": 5767168,
      "cpu_usage_percent": 16722,
      "pids_peak": 3,
      "execution_time_ms": 118
    }
  },
  {
    "stdout": "Hello, World!\n",
    "stderr": "",
    "exit_code": 0,
    "stats": {
      "memory_peak_bytes": 0,
      "cpu_usage_percent": 0,
      "pids_peak": 0,
      "execution_time_ms": 17
    }
  }
]
```

## Environment Variables

Pass environment variables to the task:

```bash
curl -X POST http://localhost:3000/api/v1/execute \
  -H "Content-Type: application/json" \
  -d '[
    {
      "cmd": "/usr/bin/env",
      "env": {
        "CUSTOM_VAR": "custom_value",
        "ANOTHER_VAR": "another_value"
      }
    }
  ]'
```

**Response:**
```json
[
  {
    "stdout": "CUSTOM_VAR=custom_value\nANOTHER_VAR=another_value\n...",
    "stderr": "",
    "exit_code": 0,
    "stats": {
      "memory_peak_bytes": 0,
      "cpu_usage_percent": 0,
      "pids_peak": 0,
      "execution_time_ms": 7
    }
  }
]
```

## Error Handling

When a command fails, you'll receive an error response:

```bash
curl -X POST http://localhost:3000/api/v1/execute \
  -H "Content-Type: application/json" \
  -d '[
    {
      "cmd": "/nonexistent/command"
    }
  ]'
```

**Response:**
```json
[
  {
    "error": "No such file or directory",
    "stats": {
      "memory_peak_bytes": 0,
      "cpu_usage_percent": 0,
      "pids_peak": 0,
      "execution_time_ms": 5
    }
  }
]
```

## Tips

- **Absolute Paths**: Always use absolute paths for commands (e.g., `/usr/bin/ls` instead of `ls`)
- **Escape Characters**: Remember to escape newlines and quotes in JSON strings (`\n` for newline, `\"` for quotes)
- **Resource Monitoring**: Check the `stats` field in responses to monitor resource usage
- **Parallel Execution**: Use arrays to run tasks in parallel and save time
- **File Size**: Keep file contents reasonable as they're included in the JSON request
